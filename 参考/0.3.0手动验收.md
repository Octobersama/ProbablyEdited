# 0.3.0 手动验收

## 安装前

1. 退出游戏，备份游戏的 `Mods/ProbablyEdited/`，以及 `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\ModData\probably_edited\` 整个数据目录。
2. 将项目 `dist/ProbablyEdited/` 内的 `ProbablyEdited.dll`、`manifest.xml`、`LICENSE`、`NOTICE` 复制到游戏 `Mods/ProbablyEdited/`，替换同名模组文件。不要用发布包覆盖个人数据目录。
3. 正常启动，保持模组 **Developer mode 关闭**。在模组列表核对版本 **0.3.0**、作者 **OctoberSama**，从设置齿轮进入工作台。

## 预设与分页

- 原有预设名称、各语言修改和当前生效选择应保留；下拉不再列出 01–36 槽位或空槽。默认每页 **100** 条，仍能切换 30/50/100/200/500 和滚轮翻阅。
- 新建一个临时预设并改名：它应从原文开始，不复制其他预设覆盖。切换“编辑预设”不应立即改变游戏文字。
- 创建两个同名临时预设，分别改动不同条目，来回切换确认内容独立；选择列表中的同名提示只用于区分，不应改写真实名称。
- 当前生效预设与最后一个预设不能删除。删除非生效临时预设时先取消一次，再确认一次；取消保留编辑，确认后仍须“保存并应用”才持久化。
- 导入目标应为“新建预设”或某个已有预设，不再选空槽。预览不能提前创建预设；确认导入仍只暂存，不直接生效。36 个上限已由自动检查覆盖，无需手动逐个创建。

## 条目选中、草稿与差异

1. 选中一条文本，将鼠标移到右侧输入区。列表的当前条目仍应保持悬停风格高亮，左侧没有 `>`。改选另一条后，旧条目恢复普通样式。
2. 修改替换文本但不暂存：列表该条显示 `*`；撤销到原来的暂存内容后 `*` 消失。再次修改并“暂存此条”，`*` 消失，已修改状态仍存在。
3. 中文原文中只替换一个字：只标记该字的删除/新增；原文删除区域为红底，**没有中间划线**。
4. 英文原文中把一个词改为共享前缀的另一个词，例如原文若为 `Continue`，改为 `Continuation`：应标记整个词，而不是只标记尾部。连续数字及字母数字混合词也作为整体比较。
5. 用长段落和多行文本检查上下滚动：红绿背景应随文本滚动、正确裁切，不盖住其他条目；复制内容不能包含高亮标记。

## 右键菜单

依次检查替换文本、预设重命名、搜索词、导出文件名；再检查原文和详细信息等只读框。

- 菜单使用游戏风格，只有 **全选、复制、粘贴、撤销、重做** 五项，顺序一致；靠近屏幕边缘时仍完整可见。
- 先选中输入中的一段文字，再右键粘贴：仅替换选区，不把整段覆盖或插到开头；草稿星号和 diff 随之更新。
- 普通键入后撤销，再重做；粘贴后也能撤销、重做。撤销后输入新内容，旧的重做分支应失效。打开菜单后直接继续键入，菜单应关闭且光标不跳回旧选区。
- 用包含中文、换行和补充平面字符的临时文本检查全选复制/粘贴：复制值完整，不截断字符。缺少某字符字形与剪贴板文本是否完整是两件事。
- 只读框可以全选、复制；粘贴、撤销、重做可见但不可用。无选区时“复制”不可用，无可撤销/重做内容时对应项不可用。
- 菜单操作不能自动提交预设重命名、暂存文本或导出文件；必须点击各自原有按钮。重命名框未获得输入焦点时也试一次右键粘贴，再点击“保存名称”，确认保存的是当前框内文字；撤销或重做后同样核对。
- 点菜单外或按 Escape 只关闭菜单；切换条目、预设或关闭输入窗口后，菜单不悬空，撤销不跨对象。
- 从存档内打开工作台，在输入框右键时确认背后的游戏世界没有同时执行交互。UI 的“已使用”标记不等于已证明游戏自己的按键轮询被阻断。

## 保存、重启与安全扫描

1. 仅用临时预设完成一次“保存并应用”，退出并重启，确认名称、修改及生效选择保留。正常保存后的工作区格式为 v3；若回退旧模组，必须同时恢复安装前的数据备份。
2. 安全兼容性另见 [安全更新兼容性核查](安全更新兼容性核查.md)。需要扫描时，在游戏可执行文件旁临时放置空 `dev.txt`，重启后按 F8 输入 `mod-scan probably_edited`；记录完整结果，而不是只记录控制台能打开。
3. 关注 `declared`、`detected`、`DEPRECATED`、`from December 10, 2026` 和拒绝原因；必要时再执行 `mod-trust probably_edited`。若有拒绝，不用 Developer mode 绕过。
4. 扫描后退出游戏，移除自己创建的 `dev.txt`，重新正常启动。测试结束可在退出游戏后恢复安装前的模组文件与个人数据备份。

反馈时附上操作步骤、实际结果、游戏版本及相关截图或日志片段；不要上传整个个人预设目录。
